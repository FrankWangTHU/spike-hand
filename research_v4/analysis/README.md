# 当前解码模型误差分析与下一轮实验设计

分析日期：2026-10-18。只读比较 baseline_v2、baseline_v3；诊断代码和结果保存在 research_v4。

## 结果适用范围

固定 split_seed=42，401 个训练 Trial、169 个验证 Trial、20 个 Session。当前固定集成 HRFS=52.0698847；读取的另一任务 v3 配置快照为 52.0646748。均为经过选择的本地开发集结果，不代表平台成绩。本次未重新训练，也未获得 58 分模型。另一个 split=43 仅验证过部分模型组合，不能视为完整 52.07 方案的独立确认。

诊断由 `diagnose.py` 生成；详细结果见 `diagnosis.json`，现有实验配置见 `experiment_inventory.json`，轨迹示例见 `trajectory_examples.png`。先对每个 Session 内 Trial 等权平均，再对 Session 等权平均；条件或阶段统计仅包括存在该条件或阶段的样本。误差使用原始坐标单位，不额外假定标定单位。

计分为 `(0.25 Wrist + 0.35 Pose + 0.20 Motion + 0.10 Bone)/0.90`。Bone 即使达到 100，总分也只增加约 1.96。Motion 的指数误差项已接近零，目前几乎全部来自相关性项；速度幅度统一放大不能改善相关系数。

| 阶段 | 帧比例 | 手腕误差 | 姿态误差 |
|---|---:|---:|---:|
| Ton 之前 | 15.25% | 26.54 | 13.66 |
| Ton 到 reward | 69.05% | 14.62 | 8.77 |
| reward 之后 | 15.80% | 11.70 | 8.70 |

Ton 是任务事件，不能把此前当作静止段；真实手腕在该段已有明显运动。逐 Trial 的手腕误差中，常量偏移占均方误差比例的平均值约 35.1%；这不是全数据统一偏移，也不是严格因果归因。姿态误差经 sigma=3 平滑后仍保留约 83.8% 原误差能量，提示缓慢变化的偏差值得优先处理；这不是正交频带分解。

后续原始事件核查：全部 570 个 held-in Trial 都满足 `Ton_frame_index = trial_start_frame - window_start_frame`，以及 `reward_frame_index = reward_frame - window_start_frame`。Ton 是试次开始，不是 go cue，更不是运动学检测的运动起点。全部 570 条记录均满足 trial_start ≤ cue_on ≤ reward，因此上述“Ton 到 reward”还包含准备和模块送入阶段，不能称为纯动作执行阶段。CSV 中的 go cue 可用于训练数据诊断，但本地没有 Data_heldout 可核查，正式推理能否依赖这些额外 CSV 列尚未确认；NPZ 中的 Ton/reward 则明确由赛题保证提供。

最差 Session 2026051502 为 42.71，最好 2026052701 为 62.68。食指/中指/无名指指尖误差分别约 13.32/14.89/14.05，拇指尖约 8.76；不同手指几何尺度也会影响误差，不能仅按原始误差设置权重。训练集 Session×condition 组常只有 1—4 个 Trial，不适合各组独立训练大模型。

统一输出时间偏移测试：0 帧为 52.07，-2/+2 帧为 48.42/48.64，-4/+4 为 42.19/42.30。没有统一平移可修复的时间错位；这不排除各神经特征具有不同最佳延迟。

## 仅用于定位的真值干预

以下操作使用验证标签，不能部署、不能作为模型成绩、不能将各项收益相加。

| 干预 | 诊断分数 | 含义 |
|---|---:|---|
| 消除各 Trial 全程平均手腕偏移 | 54.69 | 全局位置估计值得改进 |
| 用 Ton 前平均偏移修正整个 Trial | 51.43 | 初始误差不能作为全程常量直接修补 |
| 消除各 Trial 平均局部姿态偏移 | 54.27 | 存在稳定形状偏差，但独立平移关节会伤骨长 |
| 将 Ton 前预测全部替换为真值 | 57.91 | 该阶段对总分影响大；边界速度也随之变化 |
| 将 Ton 前误差人工减半 | 55.07 | 用于评估重要性，不是可实现收益预测 |

只用训练集同 Session、同 condition 事件对齐平均模板为 32.56。当前模型显著超过这一简单模板，但这并不能代替神经信号打乱等因果消融。

## 最直接的论文依据：LMLF

本地 `He - Simultaneous multi-area recordings in macaque frontoparietal cortex during a manual object-interacti.pdf`，第 20—22 页方法，第 40—41 页结果；2026-10-05 的预印本，DOI https://doi.org/10.64898/2026.09.29.754877。

论文报告 LMLF=58.09，分项 Wrist=62.99、Pose=62.58、Motion=33.24、Bone=79.84。其数据/通道/划分与当前竞赛子集不同，不能直接横向宣称谁更好。论文覆盖 40 条件和更大输入，当前数据为 9 条件、256 TX + 256 SBP；通道敏感性实验的完整配置为 1920 个有效物理通道，各自提供 TX/SBP。论文的 58.09 不是当前 512 特征数据上的已证实成绩。

LMLF 先仅用训练标签标准化并拟合 PCA，63 维坐标变为 32 维运动因子。输入特征按其与因子在 {0,1,2,3,4,6,8,12} 延迟下的相关性选取。短 GRU、长 GRU、TCN 三分支分别预测因子，经固定逆 PCA 还原坐标，再加零初始化、系数 0.25 的坐标残差。

论文配置：GRU 两层 hidden=256；TCN hidden=320，kernel=3，五个双卷积残差块 dilation=1,2,4,8,16；损失为坐标 MSE + 0.2 因子 MSE + 0.1 一阶差分 MSE；AdamW lr=1e-3、wd=1e-4、batch=8、dropout=0.15、120 epochs；融合权重 0.36/0.24/0.40。论文还描述 TCN 因果运动修正 beta=-0.5、motion scale=4.0，但所读段落没有完整运算公式，不能自行猜测并声称严格复现。Gaussian 平滑的严格因果实现也需核对代码。

值得优先验证的是输出结构、延迟选择与互补时序分支；不能一次全加后把增益归因到某一项。

## 相关方法与适用性

- LFADS：通过序列自编码器推断神经群体低维动态。神经重建好不保证行为解码好；本地论文所测试 Selected LFADS+Linear 仅 35.83，不代表整个 LFADS 家族的上限。https://pmc.ncbi.nlm.nih.gov/articles/PMC6380887/
- AutoLFADS：自动调整无监督模型超参数，计算成本更高。短期提分不是优先路线。https://www.nature.com/articles/s41592-022-01675-0
- DPAD：优先学习与行为相关的状态，再学习剩余神经动态。可借鉴行为/背景潜变量分离，而非将普通多任务 TCN 称为 DPAD 复现。https://www.nature.com/articles/s41593-024-01731-2
- BAND：所查版本为 2025 年预印本；在 LFADS 类模型上加入行为监督，保留神经变化较小但行为意义较大的运动修正。https://pmc.ncbi.nlm.nih.gov/articles/PMC11974739/
- NDT3：大规模预训练路线，但官方模型卡输入为 20ms 分箱 spike counts；当前 TX/SBP 混合特征不能不加适配直接使用。https://github.com/joel99/ndt3/blob/main/model_card.md

## 建议的实验顺序

1. 固定当前基线、预处理、计分和开发划分。新候选按整 Trial 验证，不随机拆帧。保留未用于挑选结构的确认划分；每个确认划分重训匹配基线。所有 PCA、选通道、标准化仅 fit 训练部分。
2. 用同一编码器比较直接输出与训练标签 PCA(16/32/48)+小残差；分别检查手腕绝对坐标和手腕相对姿态。先做小范围实验，限制选择次数。
3. 固定输出结构，比较无显式延迟与短/长延迟，再加仅训练集的延迟感知特征选择，检查跨 Trial 稳定性。明确选择物理通道对还是独立 TX/SBP 特征。
4. 增加 Ton 前连续残差分支与阶段加权，权重先比较 1、1.5、2。残差从零开始，阶段间平滑衔接；不假定初段静止，不将初段偏移外推全程。
5. 增加原帧率短时分支，检查当前 stride=3 对快速变化的影响；以位置和姿态为主目标，速度相关性为辅助。保持骨架软约束，避免独立关节修正破坏骨长。
6. 跨 Session 共享主干 + 小型、有正则的 Session 适配；不要为每个只有几条 Trial 的条件训练独立大网络。检查差 Session 是否稳定受益。
7. 在上述基线稳定后，再测试 DPAD/BAND 启发的行为优先潜变量与背景潜变量分离。神经重建辅助权重从小开始，避免其压过坐标监督。
8. 最后才融合确有互补误差的分支。新方案需要在确认划分与多数 Session 上持续改善，不能只凭开发集最佳数值晋级。

58 分的分项预算示例：Wrist +10、Pose +7、Motion +2 对应总分约 +5.94。这只是计分公式的目标分解，不是效果承诺。现有证据支持把主要工作投入手腕定位、局部姿态结构以及 Ton 前阶段，而不是单独加强平滑、骨长修正或堆大模型。
