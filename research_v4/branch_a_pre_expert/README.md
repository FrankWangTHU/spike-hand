# 独立 Ton 前专家实验

仅本地实验，提交次数0。划分42：401训练Trial、169验证Trial、20个Session；该划分已用于多轮开发，结果不是独立确认。

完整复制A3网络并允许全部参数更新，冻结另一份A3负责后半段；完整神经输入上下文保留。初始化来自第一轮A3，AdamW学习率1e-4，余弦60轮，batch8、hidden192、通道dropout0.25。不是只训练一个共享主干的小头。

训练损失使用Ton相对时间的smoothstep权重：Ton前0.2秒及更早权重1，Ton后0.2秒及更晚权重0，中间平滑递减。位置、速度和骨长损失均应用该区间权重。初版预测全部坐标；针对性对照只优化腕部位置及腕部差分，并保持A3的腕部相对手指姿态。

初版最佳轮次为30；腕部专用版最佳轮次为30。选择依据为固定0.2秒半宽拼接后的完整轨迹原始分，包含epoch0。最终集成替换原stacked_large成员，其他成员、权重和后处理不变。
