## Branch A：事件辅助软分段残差

问题：不同阶段的绝对位置和局部姿态误差不同，统一读出可能欠拟合。已有 metadata、condition head 和 origin_head 不等于阶段软门控。

方案：沿用 stacked_large 共享编码器与通用读出，增加三个小型低秩残差头，分别偏重 Ton 前、核心事件区间、reward 后。门控使用公开相对时间、事件进度和编码器神经状态；softmax 权重连续，残差末层零初始化。全 Trial 编码，不在事件边界重置状态。腕部与局部姿态的修正强度可不同，但第一轮只给腕部修正，避免同时改变过多设计。

初轮三个配置：A1 仅阶段损失权重（Ton 前 1.5，其他 1，按 Trial 内加权和归一化）；A2 软门控腕部残差，原损失；A3 软门控腕部+局部姿态残差，原损失。低秩宽度先固定 32，不做网格搜索。观察边界速度异常。若 D0 指向文件开头而非事件特异性，优先改上下文/初始状态，不机械强化阶段专家。

候选不依赖真实运动起点或真实坐标决定门控。后续可以用训练 go cue 作为辅助标签学习阶段，但推理必须仅用保证可用的输入，且不把预测 go cue 当成真实边界。

## Branch B：结构化运动因子输出与延迟建模

问题：全手存在系统性姿态偏差。已有输入 PCA/姿态后处理不等于监督输出因子。

先隔离输出结构：同一 stacked_large 主干、训练及输入，腕部保持独立 3D 输出，60D 相对姿态使用仅训练集拟合的 PCA，预测因子后逆变换，加零初始化的小坐标残差。初轮比较 rank16/rank32；因子损失按尺度规范化后初始权重 0.2，残差初始增益 0.25。共享姿态基底优先，不为每个仅几条样本的条件独立拟合。该设计是 LMLF 启发的适配，非论文原样复现。

第三个配置只在较好输出结构上增加短/长延迟上下文，其他不变。延迟先固定 {0,1,2,3,4,6,8,12} 帧，保留离线 v3 全段上下文，不为模仿论文而剥夺已有信息。延迟感知特征筛选是后续备选，不与输出结构第一轮捆绑；若做筛选，必须训练 Trial 内拟合并检查跨 Trial 稳定性，明确 TX/SBP 独立特征与物理通道配对的区别。

输出 PCA 验证重建误差只是表示能力诊断，不能当作可部署预测。低维约束若伤害快速细节，减弱约束/提高残差自由度，而不是通过平滑真实标签来改善表面分数。

## Branch C：评分聚合对齐的训练

问题：v3 训练对批次所有有效帧求平均；评分先 Trial 再 Session 等权。长 Trial、样本更多的 Session 会在当前训练目标中占更大权重。标准化差分惩罚也与原始坐标/实际 dt 的速度指标不同。是否造成当前瓶颈需要实验，不能先称为 bug。

保持 v3 主干和输出结构。C1：位置/骨长/差分先在每个 Trial 内平均，再进行 Session 平衡，使用一致的分层采样或无偏权重，避免重复加权。先不更改损失系数。C2：在 C1 上加入小权重、按 Trial 计算的局部速度相关性目标，使用实际 dt，妥善处理近静止维度；以 v3 已有相关性损失为直接对照。C3：保留坐标主损失，加入小权重的多时间尺度位置/差分监督；所有系数先固定，只在确认 C1 有效后推进。

不要直接用指数评分取代所有坐标损失，难样本可能梯度过小；已有 score-loss/motion-finetune 并未证明大收益。C 的核心增量是聚合与采样对齐，不是重复已有运动微调。

## 本地筛选与训练纪律

1. 三分支先各至多 3 个配置，配一个共享的匹配控制；总计约 9 个初轮候选，不做全组合。参考 stacked_large 原 220 epoch 余弦计划；早期小轮数运行仅查数值与接口，不以短跑得分淘汰收敛较慢方法。
2. 固定 split42 做开发，split43 仅作已知的次级复核，它已被使用，不称为全新盲测。
3. 每分支最多一个候选晋级。使用另一个初始化检查方向稳定性，并评估与冻结 v3 的增量。融合只试 alpha={0,0.25,0.5,1}，y=(1-alpha)*v3+alpha*new；在原始坐标预测上融合后统一后处理，禁止重复平滑/骨长修正。
4. 在看结果前固定 split44 的分层整 Trial 划分及评估规则。晋级候选与 v3 完整 8 网络在同一划分按固定轮次/学习率计划重训，不能拿 split42 的基线预测或全 heldin 权重在 split44 评估。候选/权重冻结后一次复核，不再按 split44 调参。它仍是同一 heldin 池的重划分，不是独立新数据。
5. 初始工程晋级门槛：候选包相对冻结 v3 在开发集约 +0.4 以上，固定确认划分约 +0.2 以上，至少 12/20 Session 改善，且新初始化不明显翻负。门槛是管理实验预算的经验规则，不是显著性证明；若均未达到，则不消耗平台次数。
6. 报告每分项、每阶段、每 Session 的配对差异、最差场次和推理成本；不因一个难条件上升而忽略整体下降。最多 3 个候选进入平台探索，不要求单模型必须超过 8 模型集成，但候选与 v3 的组合必须通过上述增量检查。
7. 评估输入 padding、可变长度、事件边界和 checkpoint 读回一致性。最终训练全部 heldin，统计量重新 fit 全 heldin；正式包执行去标签输入、自包含推理和输出覆盖检查，并存 SHA256。
