# Ton前位置偏移诊断与初始位置＋位移模型

本地划分42；401训练、169验证Trial，未提交平台。原A3与v3文件哈希未变。

## 误差分解

对每条Trial的Ton前腕部误差e(t)，令b=mean(e)，则mean(||e||²)=||b||²+mean(||e-b||²)。Trial先平均，再按Session等权汇总。诊断排除Ton前不足2帧的3条Trial，其余166条参与；数值与包含全部Trial的完整指标不可直接比较。

A3聚合平方误差中，整体偏移占77.14%。120/166条Trial偏移占比超过50%。未经后处理的腕部平均距离误差26.10892，使用验证真值消除均值偏移后为10.99957，仅用前5个有效点对齐后为18.30793。这些是真值辅助诊断，不是可部署结果或模型得分。

## 本轮结构与训练

独立专家继续使用完整神经信号窗口。显式分解腕部p(t)=a+d(t)：将原解码器腕部输出减去前min(5,Ton索引)个点的均值，得到零初始均值的相对位移；起始位置头读取初始区间、Ton前、全窗口的GRU特征池化，预测起始位置修正。预测锚点=原解码器锚点（停止梯度）＋修正。新增头末层零初始化，初始输出保持A3等价。真实起始位置只在训练损失中使用，推理没有坐标或go cue输入。

沿用前轮独立腕部专家：完整网络可训练，Ton附近±0.2秒smoothstep拼接，后段及手指相对姿态使用冻结A3；AdamW lr1e-4、60轮余弦、batch8、hidden192、channel dropout0.25。基础损失为早期腕部位置＋0.2倍标准化速度误差；新增0.5倍起始位置误差和0.5倍相对位移误差，距离项除以20。起始位置监督与相对位移监督共同固定分解含义。

固定拼接方式按完整轨迹原始本地分选择checkpoint，最佳epoch=50。不是直接按真值校正后的诊断分选模型。
