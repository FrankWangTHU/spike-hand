# Branch A 第二轮：学习准备/执行分界

本轮只进行本地开发实验，不提交平台。原v3与Branch A第一轮文件保持不变。

## 假设与对照

第一轮A3单模型50.79392，替换原v3主力后52.23366，相对v3仅+0.16898。原三阶段专家将Ton到reward的准备和执行混在一起。本轮用训练Trial的go cue事件作为辅助监督，学习区分这两种状态；推理接口不接收go cue，也不读取keypoint。

固定从A3开发划分42的最佳checkpoint（原训练150轮）初始化，三个方案各微调60轮，AdamW lr=1e-4，余弦60轮计划，其他预处理/模型宽度/批次/正则继承原主力。epoch0也参与最佳checkpoint选择，避免把继续训练造成的退化隐藏掉。

1. continue_a3：原三阶段模型继续训练，控制额外训练预算。
2. go4_unsupervised：四阶段残差；准备/执行分配由神经表示和公开元数据学习，不加事件辅助损失。
3. go4_supervised：同样四阶段结构，额外加入0.05权重的准备/执行二分类损失，仅在训练Trial的Ton到reward区间监督，每类先按Trial平均，再平衡两类。

四阶段模型保留原三阶段门控，将中间权重乘以(1-q)和q分给准备/执行专家。q由共享时序表示和公开事件元数据预测。原中间专家复制两份，奖励后专家移至第4个；新分类器零初始化，q初始0.5。对两个中间专家末层施加相反的小扰动，初始输出相互抵消，避免无监督对照陷入完全对称而无法学习的状态。

## 验证

`check_go4.py`验证从三阶段到四阶段初始化预测等价、变长padding不变、无监督门控梯度非零、事件辅助监督梯度有效。新增分类器不改变预测接口所需的数据字段。

`evaluate_branch.py`沿用第一轮固定v3和同一后处理，分别比较新增融合与替换stacked_large。`evaluate_phase.py`在预测之后才读取验证go cue，报告阶段平衡准确率和单变化点边界误差；另与仅使用训练Trial事件时长中位数的简单时钟基线比较。阶段预测准确不等于坐标分数提高。

本轮所有checkpoint与权重选择仍在开发划分42完成，不能当作独立确认。只有候选相对冻结v3达到约+0.4开发增益且多数Session改善，才进入额外确认；不因小幅或不稳定提高消耗平台次数。

为诊断辅助任务，原监督实验被完全重放，只额外保存第60轮权重；各已记录训练和验证指标差异为0。第60轮阶段平衡准确率0.96989060，go边界平均绝对误差0.075539秒；训练集条件时长中位数基线分别为0.92222392和0.134963秒。但该轮坐标原始分50.73319186，低于初始化50.79391849。阶段学得准，不等于坐标重建更准。
