## 冻结方案

模型、权重、训练和推理代码 SHA-256 已记录在 `reports/selection.json`。

| 分支 | 设置 | 新模型轮次 | 权重 |
|---|---|---:|---:|
| v2 三模型 | 沿用已有共享单向 GRU | 已有全量模型 | 10.48% |
| 压缩输入注意力 | 训练集神经 PCA 128 维，宽时间尺度，隐藏宽度 128 | 100 | 8.45% |
| 完整输入注意力 | 多尺度完整输入，隐藏宽度 128 | 150 | 14.84% |
| 分层双向 GRU | 每层交换正反向信息，隐藏宽度 192 | 150 | 35.68% |
| 大注意力 | 隐藏宽度 192，25% 通道屏蔽 | 180 | 19.63% |
| 录制时间双向 GRU | 公开时间戳描述慢漂移，隐藏宽度 128 | 150 | 10.91% |

共有 8 个网络。每个网络共享神经投影和时序结构，保留弱 session 适配。注意力分支结合全局注意力、局部卷积和逐帧特征。训练时按整条 trial 屏蔽通道，各时间尺度使用同一屏蔽模式。

输出分别表示绝对手腕位置和相对手腕的手指坐标，再恢复原坐标与尺度；没有自行转换毫米或厘米。集成后使用 sigma=1 帧的高斯平滑、0.5 强度的训练集骨长修正。录制时间先以 int64 做纳秒差，再转浮点，起点和尺度仅在训练子集拟合，外推范围受限。

使用公开 condition、Ton/reward 时刻及完整 trial 神经信息，属于**离线解码**，不声称支持实时因果推理。

## 验证协议

- 20 个 session、570 条 trial、144,628 帧。开发划分按 condition 分层，以完整 trial 划分，split seed=42；401 条训练、169 条验证。
- 标准化、神经 PCA、骨长等只在对应训练子集拟合。没有把同一 trial 的帧分到训练与验证，没有读取正式测试标签。
- 结构、最佳轮次和集成权重均在开发划分选择。开发分存在模型选择偏差，不能当作无偏泛化估计。
- 搜索最高分约 52.10；允许总分下降不超过 0.05 来移除冗余分支，选定 52.0647。手腕单独调权只增加约 0.02 分，未采用。
- 开发集 20/20 个 session 优于 v2；按 session 重采样的描述性增益区间约 [2.67, 3.80]，未修正模型选择偏差，不代表平台提分保证。
- 复核使用 split seed=43。新模型固定开发集选定轮次，保留原学习率计划，只在最终轮次评分，不在复核集重新早停或调权。这仍是同一 heldin 数据的另一划分，并非新的独立数据集。
- v2 分支沿用已有开发预测、复核预测与全量权重，其全量训练轮次为 140/140/180；不按本次 v3 的轮次规则重训。
- 最终新模型用完整 570 条 trial 重训。ZIP 自测去掉公开 trial 的 keypoint，只检查接口、覆盖、数值和可执行性，不是泛化评分。

## 对照实验

主要增益来自多尺度特征、通道正则化、双向交互，以及注意力与 GRU 的互补。更强正则化和更大模型不总是更好。

事件对齐条件模板约 32.56、核回归约 35.06、树模型约 37.72，未进入集成。坐标旋转、姿态 PCA 后处理、条件专家、运动损失微调和强通道屏蔽也做了对照。中断且未完成的实验不记作完整有效结果。

冻结后的描述性诊断见 `reports/error_diagnosis.json`：动作开始前的手腕误差为 26.74、动作阶段为 14.84（均为原始坐标单位），前者约为后者 1.8 倍；“40推拉：大板竖斜”和“17推拉：粗横斜”的开发分较低。此诊断没有用于再次调整本次冻结方案，也不能据此承诺某项修改会带来多少平台分。
